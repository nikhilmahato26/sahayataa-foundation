Team:
  /images/team/1.jpg ... 3.jpg

EVENTS (one folder per event — add as many photos as you like and
list the filenames in siteContent.js -> events[].photos):
  /images/events/blood-donation-camp/cover.jpg + 1.jpg, 2.jpg, 3.jpg
  /images/events/medical-camp/cover.jpg + 1.jpg, 2.jpg, 3.jpg
  /images/events/education-drive/cover.jpg + 1.jpg, 2.jpg

Until a photo is added, the site shows a clean branded placeholder
automatically — nothing breaks.

DONATE QR: the QR is generated automatically from the UPI ID in
siteContent.js. If you have a printed QR image, drop it here as
donate-qr.png and set donate.qrImage = '/donate-qr.png' in siteContent.js.
